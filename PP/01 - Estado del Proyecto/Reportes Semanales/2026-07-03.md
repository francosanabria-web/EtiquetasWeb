# Reporte semanal — Sistemas Pañol — 2026-07-03

## 1. Resumen ejecutivo

Esta semana el equipo puede empezar a usar un **portal web único** desde la red del pañol: ingreso con usuario, acceso a indicadores de gestión (stock, consumo, reposición y activos fuera de planta) y a la **minuta de reunión** con envío de correo. Las **etiquetas** siguen operativas en la red local, ahora con búsqueda más tolerante y arranque automático del servicio de impresión. La app de escritorio sigue siendo la herramienta principal para registrar salidas, reportes de gastos y activos; esas funciones en la web aún están planificadas. El avance más visible para jefatura es poder **ver indicadores y preparar la minuta sin abrir el Excel a mano**, desde una misma pantalla en la PC del pañol.

## 4. Documentación técnica — avance

**Documentación de arquitectura (`03 - Documentacion Tecnica/`):**  
El vault incluye descripción de servicios (API, correo, shell, Firestore, esquema MariaDB planificado). Esta semana no se registraron archivos nuevos masivos en esa carpeta; el **Roadmap** se actualizó al 2026-07-01 con el estado de KPIs y la doble vía de Minuta.

**Decisiones de arquitectura (traducidas a lenguaje claro):**

| Decisión | Qué significa para el equipo |
|---|---|
| MariaDB como base central futura | Los datos del pañol migrarán a una base más robusta en la PC servidor; por ahora se usan archivos Excel y bases locales temporales |
| No tocar la app móvil de consultas durante la migración | El buscador en el celular sigue funcionando igual mientras se construye el sistema nuevo |
| La app móvil sigue leyendo la nube; el sistema nuevo la alimentará | No hay que cambiar hábitos del operario en el celular de inmediato |
| Todo corre en la PC Windows del pañol | No depende de un servidor en internet para operar día a día |
| Prueba de 7 días en paralelo (planificado) | Antes de reemplazar el escritorio, se usarán ambos sistemas una semana para comparar |
| Misma configuración de correo que el escritorio | Los mails salen con las mismas cuentas y destinatarios del Excel de correos |
| Documentación en Obsidian (carpeta compartida PP) | El estado del proyecto queda escrito en la unidad del pañol, no solo en el código |
| Cola de etiquetas en archivo local, no en la nube | Menor costo y más control; la impresora consulta pedidos pendientes en la red |
| Minuta en portal con guardado local (evolución reciente) | Las reuniones y pedidos pueden quedar registrados para la semana siguiente, no solo en el mail |
