# Reporte semanal — Sistemas Pañol — 2026-07-09

## 1. Resumen ejecutivo
Esta semana se ordenó mejor el portal para uso en reunión: ahora **Activos fuera de planta** tiene su módulo propio, con datos más claros para seguimiento operativo (incluye remito, pedido y OC). También se reforzó la minuta para trabajo real de equipo: guarda borrador por usuario, permite detallar sectores comprometidos en texto libre y mejora la gestión de destinatarios de correo. En KPIs se mantuvieron los indicadores clave, pero se sacó la parte de activos para no mezclar seguimiento operativo con tablero gerencial. El impacto práctico es que hoy se puede mostrar en reunión una navegación más clara, con menos confusión entre “ver indicadores” y “gestionar casos”.

## 4. Documentación técnica — avance
En documentación técnica se mantuvo el mapa de servicios y se consolidó el alcance de APIs ya usadas en operación local (KPIs, correo, minuta). Además, en el vault quedó reflejada la separación de Activos fuera de planta como módulo propio, junto con roadmap y pendientes actualizados.

Decisiones de arquitectura traducidas a lenguaje simple:
- Se mantiene MariaDB como destino final para ordenar toda la información en una base central.
- Se conserva la app móvil actual mientras se migra el resto, para no cortar el servicio.
- El sistema nuevo sigue pensado para correr en la PC del pañol, cerca de los Excel operativos.
- Se definió separar “indicadores” de “seguimiento operativo”, por eso Activos dejó de estar dentro de KPIs.
